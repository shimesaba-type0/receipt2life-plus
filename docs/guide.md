# 使い方

自分用のガイドです。スマホで読める短さにしています。実在の店名・金額・URLは書かず、例はすべてダミーです。

## 画面ごとの使い方

### ホーム

- 一番上に日付。その下に「今日 ¥0・0件の記録」が小さな1行で出る(レシートをその日に取り込むとは限らず、0円の日が普通にあるため)
- 「今月の割引」が大きく出る。「今月の内訳」の見出しの横に、期間と件数(例: 10月1日〜12日・18件を記録)が出る。今月の合計は、内訳のドーナツの中央に出る
- 「今月の内訳」は大分類ごとの割合を、ドーナツグラフで見せる。大きい区分(上位5つまで、10%以上)には、リングの中に % が入る。小さい区分は、横の(スマホでは下の)一覧で金額と % を見る。中央は今月の合計。「今月の割引」は、レシートに印字された割引の合計
- 「今月の割引」は、今月のレシートに印字された割引(値引き・割引・クーポンなど、マイナスの明細の行)の合計と件数。割引がないときは「今月の割引はまだありません」と出る
  - 数えられるのは、レシートに印字された割引の行だけ。最初から安い値段のものや、印字されないポイント還元は見えない(カードにも「印字された割引行のみ」と書いてある)
  - 合計だけの記録(明細がない支出)は数えない。金額がマイナスのものも、返品・払い戻しの可能性があるので割引にしない
  - 店別・カテゴリ別・月別の割引は、AIに「今年の割引を店別に出して」と頼む
- 「要確認の記録」があれば、上に件数が出る。タップして確認する
- 「最近の記録」から、その日を開ける。「今日の記録を開く」の緑のボタンで、今日の詳細へ

### カレンダー

- 日ごとの支出の合計が出る。祝日は日付の横に「祝」と出る
- 前の月、次の月は左右の矢印。月の表示をタップすると「年月を選んで移動」が開き、年と月、または日付を指定して飛べる(「今月へ」で戻る)
- 出来事(メモ)は、期間の帯として描かれる。重なるときは段が分かれる。下の「今月の出来事」に一覧が出る
- 日をタップすると、日の詳細へ(PCは右に簡易表示が出る)

### 日の詳細

- **支出を追加**: 「支出を追加」から、金額(円)、店名、カテゴリ、支払方法、税金のフラグ、メモを入れて保存
- **並び順と時刻**: その日の支出は、決済時刻の早い順(時刻なしは最後)。時刻があれば店名の横に小さく出る(くわしくは下の「レシートの情報」)
- **支出を開く**: 一覧の行をタップすると、その支出の「明細」ページが開く(見るだけ。編集は「編集」ボタンから。くわしくは下の「明細(レシートの行ごとの記録)」)
- **税金のフラグ**: 医療費控除、セルフメディケーション税制、寄附金控除から1つ選べる。金額の記録と合計を出すだけで、控除の判定はしない
- **この日のメモ(出来事)**: 「メモを追加」で、内容、色、開始日、終了日(省略で1日)を入れる。複数日なら、カレンダーに帯で出る
- **写真**: 「写真を追加」で複数まとめて選べる(1回20枚まで)。端末で自動的に小さくしてから保存する。タップすると拡大。「選択」を押すと、複数選んでまとめて削除できる(「すべて選択」もある)。削除は元に戻せない
- **リンク**: Xの投稿かYouTubeの動画のURLを貼って、この日に残せる。タイトルは任意で、あとから編集できる。同じURLは二重に追加されない
- **座席の記録**: 映画館などの席の評価を残せる。「座席を記録」から、作品名・公演名(任意。映画のタイトルやライブ名)、会場名(既存の会場名が候補に出るので、同じ表記にそろえる)、スクリーン・エリア(任意。ホール・ブロックなど。選んだ会場の候補が出る)、座席(例: F-5)、席種(任意。プレミアムシート、内野指定席など)、評価(★1〜★5のボタン。5が最良。もう一度押すと外れる)、一言(任意)を入れて保存。一覧は、作品名(あれば太字)・会場名・スクリーン・エリア名(あれば。特徴メモがあれば小さく添える)・座席と評価(席種があれば座席の隣に「F-5(プレミアムシート) ★4」のように添える)・一言を、別の行に出す。会場やスクリーンの名前変更・特徴メモの設定は、画面ではなくAIに頼む(「スクリーン5の特徴に「前方は首が疲れる」と書いて」)。記録をタップすると編集・削除。PC幅のカレンダーの右側にも一覧が出る(読み取りのみ)

### 支払方法(口座)

- メニューの「支払方法」(`/accounts`)で、現金・カードなどを追加・名前変更・削除できる。名前を変えると、使っている支出の表示も新しい名前になる
- 使っている支出がある支払方法を消すときは、移し先の支払方法を選ぶ(支出は消えない)
- AI(Claude など)に頼むときは「『PayPay』の支払方法を追加して」のように言う。AI は確認してから追加する。未登録の支払方法名で登録しようとすると、自動では増えず、エラーになる

### カテゴリ(アイコン)

- メニューの「カテゴリ」(`/categories`)で、大分類の下のサブカテゴリを増やす・名前や大分類を変える・消す。各サブカテゴリの行の先頭に、アイコンが丸の中に出る
- 追加・編集のフォームの「アイコン」で、食事・カフェ・タクシー・映画・旅行など31個から選ぶ。選んだものをもう一度押すと外せる。未設定は「その他」(・・・)と同じ見た目
- 支出の行・明細・ホームの最近の記録では、カテゴリの文字の前に小さなアイコンが付く(文字も残る)
- AI(Claude など)にカテゴリを作ってもらうときも、名前に合うアイコンが付く。変えたいときは「『タクシー』のアイコンを車にして」のように頼める

### サブスク・固定費(`/subscriptions`)

- 下のタブの「メニュー」(スマホ)、またはPCの左メニューの「サブスク・固定費」から開く。動画配信・保険・通信費など、決まった額を払い続けているものを登録しておく一覧
- ここに登録しても支出には数えない(別枠)。実際に払った分は、これまでどおりレシートとして記録する
- 一番上に、契約中の「月あたり」と「年あたり」の合計。年払いの月あたりは、年額を12で割って四捨五入した金額。下に、月あたりの金額を大きい順に積んだ横棒と、名前・金額・割合の凡例が出る
- 一覧は月払いと年払いに分かれる。年払いは、更新月を入れると「次の支払い: 2027年3月」が出る。金額を変えると「値上がり +¥300(10/12)」のように前回との差が出る。「金額を確認した(変わっていない)」を押すと、確認した日が「金額の確認: 10/12」に残る
- 「編集」で名前・種類(サブスク/保険/その他の固定費)・金額・周期・更新月・支払日・URL(https のみ)・メモを直せる。「契約中」を外すと解約済みになり、合計に入らず、下の「解約済み」にまとまる。削除は確認のあとに実行する
- 「追加」から新しい項目を登録できる。AI(Claude など)に「◯◯のサブスクを月額◯円で登録して」と頼んでも追加できる

### 税額(`/tax`)

- 下のタブの「メニュー」(スマホ)、またはPCの左メニューの「税額」から開く
- レシートに印字された消費税額を、税率ごとに合計する。期間は「今月」「先月」「今年」「昨年」「期間指定」(開始日と終了日)から選ぶ(確定申告の準備には「昨年」)
- 一番上の「確定申告の参考」に、支出に付けた「税金のフラグ」の合計が出る(同じ期間)。「セルフメディケーション税制」、「医療費(交通費を含む)」、「医療費(交通費を含まず)」の3行。医療費は、病院代や処方された薬代に「医療費控除」のフラグを付けておく。交通費は、大分類が「交通」のカテゴリ(病院の駐車場代、通院の電車代など)の支出で、注記に金額が出る。控除の対象になるか・控除額・上限の判定はしない(ご自身で確認する)
- 表は「税率・税額の合計・対象金額の合計・件数」。下に合計の行が出る。「月別に表示する」をオンにすると、月ごとの表に分かれる
- 集計するのは、支出の「税の内訳」(下の「税率と税の内訳」)に入れた印字どおりの数字だけ。明細の行の税率から税額を計算することはしない
- 下に「税額の記録がない支出: N件(¥…)」が出る。この表に含まれていない支出の数と金額。すべてに記録があれば「すべて税額の記録があります」
- 対象金額に税込と税抜が混ざっていると、その行に「税込・税抜が混在」と出る(対象金額の合計は目安として見る)

### エクスポート(バックアップと読み込み)

- 下のタブの「メニュー」(スマホ)、またはPCの左メニューの「エクスポート・バックアップ」から開く
- 「バックアップをダウンロード」で、全期間の記録をJSONLファイルで保存する。**写真は含まれない**。ファイルは実データなので、公開の場所には置かない
- 「バックアップを読み込む」で、ファイルを選んで戻す。すでにある記録は上書きせず、重複はスキップする。5MB・5,000行まで。結果(登録、重複スキップ、既にある、読めなかった行)が出る
- 「日記として読む(Markdown・HTML)」: 月・年・日付の範囲(366日まで)を選んで、サマリ・カテゴリ別(表と円グラフ)・カレンダー・期間メモ・日別の記録を1つのファイルにする。写真は枚数とキャプションだけ(画像は含まれない)。HTMLはCSSつきの1ファイルで、スクリプトを含まない
- 「AIとつなぐ(MCP)」(メニュー): MCPサーバーのURL(いま開いているアドレス + /mcp)のコピーと、Claude.ai への登録手順。ヘッダー(PC)とメニュー(スマホ)にGitHubのページへのリンクがある

### PCとスマホの違い

- スマホ: 下に「ホーム / カレンダー / 今日 / メニュー」のタブ。「メニュー」を押すと下からシートが出て、毎日は使わない「カテゴリ」「支払方法」「サブスク・固定費」「税額」「エクスポート・バックアップ」「AIとつなぐ(MCP)」へ移れる(×・Esc・外側のタップで閉じる)。カレンダーの日をタップすると、「今月の出来事」の下にその日のプレビューが出る(支出・出来事・写真・座席。見るだけ)。「詳細を開く」でその日のページへ移る
- PC: 画面の上に横長のヘッダー(ロゴと「今日の記録を開く」)があり、その下の左メニューに「ホーム / カレンダー / カテゴリ / 支払方法 / サブスク・固定費 / 税額 / エクスポート・バックアップ / AIとつなぐ(MCP)」。カレンダーの日をクリックすると、右に詳細が出る。ダブルクリックすると、その日の詳細ページへ移る。写真は枠へのドラッグ&ドロップでも追加できる
- カレンダーのプレビュー(スマホは「今月の出来事」の下、PC は右)は、見るだけ。日付をタップ、または下の「この日を確認する」ボタンで、その日のページへ移る。プレビューの支出の行をタップすると、その明細ページへ移る
- できることは同じ

### ホーム画面に追加(PWA)

アプリのように開けるようになります。

- iPhone(Safari): 共有ボタン → 「ホーム画面に追加」
- Android(Chrome): メニュー → 「ホーム画面に追加」または「アプリをインストール」
- 開くたびに、ログイン(Cloudflare Access)が求められることがある。アイコンが出ない場合は [setup.md](setup.md) の「画面(Web UI)を出す」を見る

## 明細(レシートの行ごとの記録)

1枚のレシートを、品名と金額の行ごとに記録できます。行ごとにカテゴリや税金のフラグを変えられるので、「スーパーのレシートの中の日用品」「ドラッグストアのレシートの中の薬」を分けて集計できます。画面でもAIからも使えます。

### 画面での見方

- 日の詳細の支出の行、またはホームの「最近の記録」をタップすると、その支出の**明細ページ**が開く。ここは見るだけで、間違えて書き換えることはない
- 上に合計(金額、店名、日付、支払方法、「要確認」)、カテゴリ・税金のフラグ・メモ。その下に明細の行(品名、金額、カテゴリ、税金のフラグ)が並ぶ。値引きは「-¥80」のようにマイナスで出る。行のカテゴリが空の行は、レシートのカテゴリで表示される
- 行の下に「明細の合計」が出て、レシートの合計と合っていれば「レシートの合計と一致」と出る。明細が無い支出は「明細はありません(1行の支出です)」
- 紐づけた写真(タップで拡大)と、「写真を追加」(この支出に写真を紐づけて追加する画面が開く)、紐づけたリンクも、このページにある
- 左上の戻るボタンで、その日の画面に戻る

### 画面での編集

- 右上の「編集」を押すと、同じページがフォームに変わる。「キャンセル」で何も変えずに見るだけに戻る。保存すると見るだけに戻る
- 金額、店名、日付、カテゴリ、支払方法、税金のフラグ、メモを直せる
- **明細の行**: 「行を追加」で行が増え、行ごとに品名、金額(値引きはマイナス)、カテゴリ、税金のフラグ、メモを入れる。「×」でその行を消す。行のカテゴリや税金のフラグを空(「取引のカテゴリに従う」)にすると、レシート全体の値になる。登録のときに明細を入れなかった支出も、ここで明細を足せる
- **一括**: 「すべて同じカテゴリにする」でカテゴリを選んで「すべてに設定」を押すと、レシートのカテゴリがそれになり、全行のカテゴリは空になる。税金のフラグも同じ
- **合計の確認**: 「明細の合計 ¥X / レシートの合計 ¥Y(差 ¥Z)」が出る。合っていないあいだは保存できない。「合計に合わせる」を押すと、レシートの金額が明細の合計になる。行を全部消すと、明細なし(合計だけ)の支出になる

### 画面での削除

- 明細ページの下の「この支出を削除」を押すと、確認が出る。「消えるもの: 明細N行・写真N枚・リンクN件」が見える。元に戻せない
- 写真が紐づく支出は、「写真もいっしょに削除する」にチェックを入れたときだけ消せる。チェックを入れないと「削除する」は押せない
- 削除すると、その日の画面に戻る

### AIからの使い方

- **登録**: レシートの写真を貼って「明細ごとに登録して」。AIが品名と金額の行をそのまま記録する。値引きはマイナスの行になる(品目の下にインデントや括弧で書かれた値引きも、品目の金額は変えず、別のマイナスの行として印字どおりに記録する。レシートの印字がマスター)。明細の合計がレシートの合計と合わないと登録されず、AIが読み直す。それでも合わないときは「端数・調整」の行で合わせるか、あなたに確認する
- **カテゴリ**: 全部同じなら、レシート(取引)のカテゴリだけ。違う行にだけ行のカテゴリを付ける(例: 「洗剤だけ日用品にして」)。カテゴリを決めずに登録すると、同じ店の前回のカテゴリが自動で使われる
- **税金のフラグ**: 「薬の行だけセルフメディケーションにして」のように、行ごとに付けられる
- **集計**: 「今月のカテゴリ別の合計」は、明細の行ごとのカテゴリで分かれる。ホームの「今月の内訳」も同じ。今日・今月の合計と件数(レシートの数)は今までどおり
- **割引(お得金額)**: 「今月の割引はいくら?」「今年の割引を店ごとに出して」。AI は `summarize` の `discounts_only: true` を使い、レシートに印字された割引行(マイナスの明細)だけを合計する。印字されない割引やポイント還元は含まれない
- **修正**: 「さっきのレシートの明細を直して」。明細は丸ごと置き換わる。明細を消して合計だけに戻すこともできる
- **削除**: 支出を消すと明細もいっしょに消える。写真が付いた支出は、AIに「写真もいっしょに消して」と頼めば消せる(取り消せない)
- 明細は任意。今までの記録や、合計だけの記録はそのまま使える
- 日の詳細の「支出を追加」には、明細の入力欄は無い。明細つきで登録したいときはAIに頼むか、登録したあとに明細ページで「編集」から入れる

## 税率と税の内訳(消費税)

レシートに印字された消費税の税率と税額を、**印字どおりに**残せます。こちらで税額を計算したり、税率を決めつけたりはしません(税率は変わることがあるので、1% や 0.5% のような数字もそのまま入ります)。医療費控除などの「税金のフラグ」とは別のものです。

### 画面での見方

- 明細ページの明細の行に、税率が小さく添えられる(例: 「8% ※」。印字の記号があれば一緒に)
- 「税の内訳」のブロックに、税率ごとの表(税率・対象金額・消費税)が出る。対象金額が税込か税抜か分かっていれば「(税込)」のように添える。記録が無ければ「税の内訳は記録されていません」

### 画面での編集

- 明細ページの「編集」で、明細の各行に「税率(消費税。印字どおり)」と「印字の記号(任意)」が出る。税率は「未設定・10%・8%・0%・その他(数字を入力)」から選ぶ。その他を選ぶと、数字(例: 1、0.5)を入れる欄が出る。選択肢に無い税率で記録されていた行は「その他」に数字が入った状態で開く
- その下の「税の内訳」で、「税率の行を追加」を押して、税率ごとに、対象金額・消費税額・税込か税抜か(任意)・印字の記号(任意)を入れる。「×」でその行を消す。印字が無い項目は空欄のまま。同じ税率の行は1つだけ
- 内訳の合計がレシートの合計と合わなくても保存できる(印字どおりが正しいので)。保存したあと、上に注意が出ることがある

### AIからの使い方

- レシートの写真を貼って「税率と税額も登録して」と頼む。AI が、明細の行の税率(印字の「※」や「軽」などの記号を、レシートの凡例を見て数字にする)と、レシート下部の「10%対象 ¥1,100 消費税 ¥100」のような内訳を、印字どおりに入れる
- 記号の意味が分からない・内税か外税か分からない・印字が薄いときは、AI は推測せずに聞いてくる
- 合計は「今年の税率別の消費税の合計を出して」。AI は `summarize_tax` を使い、税の内訳が無い支出の件数と金額も一緒に伝える

## レシートの情報(時刻・店の連絡先)

後から店に問い合わせることがあるので(例: タクシーの領収書)、レシートに印字された時刻、店の電話番号・住所、事業者登録番号、対応した人、レシート番号・伝票番号、レジ番号、店番号を残せます。すべて任意で、レシートに無いものは空のままです。

### 画面での見方

- 支出のページ(日の詳細の行をタップ)の日付の隣に「14:32」と時刻だけ出る(時刻がなければ出ない。レシートの時刻は決済時刻しかないので「決済時刻」の文字は付けない)
- 「店舗の情報」のブロックに、電話(タップで発信できる)、住所(「コピー」ボタン)、事業者登録番号(「コピー」ボタン)、対応した人、レシート番号・伝票番号、レジ番号、店番号が並ぶ。全部空ならブロックごと出ない
- コピーが使えない環境では、「コピー」を押すと文字が選択状態になる。長押しなどでコピーする
- 日の詳細の支出の行には、時刻があれば店名の横に小さく「14:32」と出る。その日の支出は、決済時刻の早い順に並ぶ(時刻のないものは最後に、登録した順)

### 画面での編集

- 支出のページの「編集」で、「レシートの情報」の入力欄が出る(時刻(日本時間)、店の電話番号、店の住所、事業者登録番号、対応した人、レシート番号・伝票番号、レジ番号、店番号)。空欄にして保存すると、その項目が空になる
- 事業者登録番号は `T` と数字13桁。全角・小文字・ハイフンや空白が入っていても、欄を離れると `T0000000000000` の形にそろう。形が違うと注意が出て、保存できない
- 日の詳細の「支出を追加」には、この欄は無い。登録したあとに、支出のページの「編集」から入れる(店名の候補を選んだときは、電話・住所・登録番号が自動で入る。下の「店名の候補」)
- 「レシート番号・伝票番号」は P20261003152814 のような長い番号、「レジ番号」は 0005、「店番号」は 007832 のような店舗コード。それぞれ別の項目で、30〜50文字まで

### 店名の候補(入力の手間を減らす)

日の詳細の「支出を追加」と、支出ページの「編集」の店名欄は、入力の途中で、過去に登録した店を候補に出します。

- 打つたびに絞り込まれる。店名のほか、**電話番号**(ハイフンの有無は無視。一部でも可)、**住所**、**カテゴリ名**でも探せる
- 候補には、店名・カテゴリ(アイコン付き)・電話番号・最後に使った日・使った回数が出る。よく使う店ほど上に出る
- 候補を選ぶと、前回のその店の内容(カテゴリ、支払方法=口座、電話番号、住所、事業者登録番号)が入る。**すでに入力した欄は上書きせず、空欄にだけ**入る。入った欄は「前回の内容を入れました: カテゴリ、支払方法」と出る
- キーボードでは、上下キーで選び、Enter で決定、Esc で閉じる。日本語の変換中の Enter は決定にならない
- 候補が無いときは「新しい店として登録します」と出る。候補を読み込めないときも、そのまま入力して保存できる

### AIからの使い方と、読み取れないレシート

- 登録: レシートの写真を貼って「登録して」と頼むと、AI が印字のある項目だけ拾って登録する。印字が無い項目は空のまま(AIは推測で埋めない)
- **読み取れないレシート**: 薄くて読めない項目があるとき、AI は推測で登録せず、先に次の3つから選ぶよう聞いてくる。(1) 値を教える、(2) 合計金額だけ登録する(明細は省略)、(3) 登録をやめる。あなたが決めるまで登録されない。電話番号だけ薄い、のように一部だけ読めないときは、その項目を空にして登録し、結果を知らせてくれる。あとで補いたければ「さっきの支出の電話番号を 03-0000-0000 にして」と頼む
- 探す: 「電話番号 03-0000-0000 の支出を探して」「担当が山田のレシート」。電話番号はハイフンなしの数字だけでも探せる
- 直す・消す: 「さっきの支出の登録番号を T0000000000000 にして」「電話番号を消して」

## AIへの頼み方の例

AI(Claude)をつないでおく必要があります([connect-claude.md](connect-claude.md))。次のように話しかけます。

| やりたいこと | 頼み方の例 |
| --- | --- |
| レシート写真から支出を登録 | レシートの写真を貼って、「これを登録して」。店名・金額・日付をAIが読み取る。1枚に複数のレシートがあれば、別々の支出になる |
| 明細ごとに登録 | レシートの写真を貼って、「明細ごとに登録して。洗剤は日用品で」。品名と金額の行ごとに記録する。登録したら、その支出の明細ページで確認できる |
| 写真を残す | 「今日のレシート写真を残したい」「この支出に写真を付けたい」。AIが返すリンクを開き、画面で写真を選ぶ(チャットから写真は送れない) |
| 座席を記録する・席選びの参考にする | 「今日の映画「ダミー作品」、A映画館のスクリーン5のF-5は前すぎて首が疲れた。★2で記録して」(作品名・公演名も一緒に残せる。野球場なら「内野指定席の12列5番、見やすかった」のように席種も)。次に「F-5ってどうだった?」「A映画館のスクリーン5でおすすめの席は?」と聞くと、AIが過去の評価(平均と一言)をまとめて教える。会場名・スクリーン名は、AIが先に既存の会場を見て同じ名前を使い、新しい名前を作る前にあなたに確認する |
| リンクを残す | 「この投稿を今日のメモとして残して」とURLを渡す。XかYouTubeのURLだけ。タイトル取得や埋め込みはしない |
| 期間の集計 | 「先月のカテゴリ別の合計を出して」「今年の店ごとの合計は?」 |
| レシートの情報を残す・探す | 「レシートの時刻と電話番号も登録して」「電話番号 03-0000-0000 の支出を探して」。読み取れない項目は、AIが登録前に確認してくる(上の「読み取れないレシート」) |
| 税金の合計 | 「今年のセルフメディケーションの合計を出して」。フラグを付けた支出の合計だけで、控除の判定はしない |
| 消費税を税率別に集計 | 「今年の消費税を税率別に合計して」「月別に見せて」。税の内訳が記録されていない支出の件数・金額も一緒に出る |
| 税金のフラグを付ける | 「このドラッグストアのレシートは医療費控除にして」「さっきの支出のフラグを外して」 |
| 出来事の登録 | 「10月3日から5日まで旅行、青で登録して」 |
| 支出の修正・削除 | 「さっきの支出の金額を修正して」。削除は取り消せないので、内容を見てから許可する。写真が付いた支出は「写真もいっしょに消して」 |
| カテゴリを調べる | 「使えるカテゴリと支払方法を教えて」 |
