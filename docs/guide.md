# 使い方

自分用のガイドです。スマホで読める短さにしています。実在の店名・金額・URLは書かず、例はすべてダミーです。

## 画面ごとの使い方

### ホーム

- 今日と今月の合計が大きく出る
- 「今月の内訳」は大分類ごとの割合。「メモ付きの支出」は、メモを付けた支出の割合
- 「要確認の記録」があれば、上に件数が出る。タップして確認する
- 「最近の記録」から、その日を開ける。「今日の記録を開く」の緑のボタンで、今日の詳細へ

### カレンダー

- 日ごとの支出の合計が出る。祝日は日付の横に「祝」と出る
- 前の月、次の月は左右の矢印。月の表示をタップすると「年月を選んで移動」が開き、年と月、または日付を指定して飛べる(「今月へ」で戻る)
- 出来事(メモ)は、期間の帯として描かれる。重なるときは段が分かれる。下の「今月の出来事」に一覧が出る
- 日をタップすると、日の詳細へ(PCは右に簡易表示が出る)

### 日の詳細

- **支出を追加**: 「支出を追加」から、金額(円)、店名、カテゴリ、口座、税金のフラグ、メモを入れて保存
- **支出を編集・削除**: 一覧の行をタップすると編集。保存のほか削除もできる(写真が付いた支出は、先に写真を消す)
- **税金のフラグ**: 医療費控除、セルフメディケーション税制、寄附金控除から1つ選べる。金額の記録と合計を出すだけで、控除の判定はしない
- **この日のメモ(出来事)**: 「メモを追加」で、内容、色、開始日、終了日(省略で1日)を入れる。複数日なら、カレンダーに帯で出る
- **写真**: 「写真を追加」で複数まとめて選べる(1回20枚まで)。端末で自動的に小さくしてから保存する。タップすると拡大。「選択」を押すと、複数選んでまとめて削除できる(「すべて選択」もある)。削除は元に戻せない
- **リンク**: Xの投稿かYouTubeの動画のURLを貼って、この日に残せる。タイトルは任意で、あとから編集できる。同じURLは二重に追加されない

### エクスポート(バックアップと読み込み)

- ホームの右上、またはPCの左メニューの「エクスポート」から開く
- 「バックアップをダウンロード」で、全期間の記録をJSONLファイルで保存する。**写真は含まれない**。ファイルは実データなので、公開の場所には置かない
- 「バックアップを読み込む」で、ファイルを選んで戻す。すでにある記録は上書きせず、重複はスキップする。5MB・5,000行まで。結果(登録、重複スキップ、既にある、読めなかった行)が出る
- 「日記として読む(Markdown)」は準備中

### PCとスマホの違い

- スマホ: 下に「ホーム / カレンダー / 今日」のタブ
- PC: 左のメニューに「ホーム / カレンダー / エクスポート」。カレンダーの日をタップすると、右に詳細が出る。写真は枠へのドラッグ&ドロップでも追加できる
- できることは同じ

### ホーム画面に追加(PWA)

アプリのように開けるようになります。

- iPhone(Safari): 共有ボタン → 「ホーム画面に追加」
- Android(Chrome): メニュー → 「ホーム画面に追加」または「アプリをインストール」
- 開くたびに、ログイン(Cloudflare Access)が求められることがある。アイコンが出ない場合は [setup.md](setup.md) の「画面(Web UI)を出す」を見る

## 明細(レシートの行ごとの記録)

1枚のレシートを、品名と金額の行ごとに記録できます。行ごとにカテゴリや税金のフラグを変えられるので、「スーパーのレシートの中の日用品」「ドラッグストアのレシートの中の薬」を分けて集計できます。**まだ画面には出ません**(表示・編集の画面は別の更新で追加予定)。今はAI経由で使います。

- **登録**: レシートの写真を貼って「明細ごとに登録して」。AIが品名と金額の行をそのまま記録する。値引きはマイナスの行になる。明細の合計がレシートの合計と合わないと登録されず、AIが読み直す
- **カテゴリ**: 全部同じなら、レシート(取引)のカテゴリだけ。違う行にだけ行のカテゴリを付ける(例: 「洗剤だけ日用品にして」)。カテゴリを決めずに登録すると、同じ店の前回のカテゴリが自動で使われる
- **税金のフラグ**: 「薬の行だけセルフメディケーションにして」のように、行ごとに付けられる
- **集計**: 「今月のカテゴリ別の合計」は、明細の行ごとのカテゴリで分かれる。ホームの「今月の内訳」も同じ。今日・今月の合計と件数(レシートの数)は今までどおり
- **修正**: 「さっきのレシートの明細を直して」。明細は丸ごと置き換わる。明細を消して合計だけに戻すこともできる
- **削除**: 支出を消すと明細もいっしょに消える。写真が付いた支出は、AIに「写真もいっしょに消して」と頼めば消せる(取り消せない)
- 明細は任意。今までの記録や、合計だけの記録はそのまま使える
- 画面との関係: 明細のある支出の金額を画面(日の詳細)で変えると、明細の合計と合わずに保存できない。金額を変えるときはAIに「明細も直して」と頼む

## AIへの頼み方の例

AI(Claude)をつないでおく必要があります([connect-claude.md](connect-claude.md))。次のように話しかけます。

| やりたいこと | 頼み方の例 |
| --- | --- |
| レシート写真から支出を登録 | レシートの写真を貼って、「これを登録して」。店名・金額・日付をAIが読み取る。1枚に複数のレシートがあれば、別々の支出になる |
| 明細ごとに登録 | レシートの写真を貼って、「明細ごとに登録して。洗剤は日用品で」。品名と金額の行ごとに記録する |
| 写真を残す | 「今日のレシート写真を残したい」「この支出に写真を付けたい」。AIが返すリンクを開き、画面で写真を選ぶ(チャットから写真は送れない) |
| リンクを残す | 「この投稿を今日のメモとして残して」とURLを渡す。XかYouTubeのURLだけ。タイトル取得や埋め込みはしない |
| 期間の集計 | 「先月のカテゴリ別の合計を出して」「今年の店ごとの合計は?」 |
| 税金の合計 | 「今年のセルフメディケーションの合計を出して」。フラグを付けた支出の合計だけで、控除の判定はしない |
| 税金のフラグを付ける | 「このドラッグストアのレシートは医療費控除にして」「さっきの支出のフラグを外して」 |
| 出来事の登録 | 「10月3日から5日まで旅行、青で登録して」 |
| 支出の修正・削除 | 「さっきの支出の金額を修正して」。削除は取り消せないので、内容を見てから許可する。写真が付いた支出は「写真もいっしょに消して」 |
| カテゴリを調べる | 「使えるカテゴリと口座を教えて」 |
